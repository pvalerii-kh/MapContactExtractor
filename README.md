# MapContactExtractor 🚀

**MapContactExtractor** — это легкое и эффективное десктопное приложение на Python для автоматического извлечения адресов электронной почты (email) со списков веб-сайтов. Приложение разработано для маркетологов, специалистов по продажам и парсеров данных, которым необходимо быстро находить контактную информацию компаний (например, после выгрузки баз из Google Maps или Яндекс.Карт).

---

## ✨ Ключевые возможности

* ⚡ **Параллельная обработка (Асинхронность)**: Работает на движках `Playwright` и `asyncio`, запуская парсинг в несколько потоков (настраиваемый лимит вкладок, по умолчанию — 3 в параллели), что ускоряет сбор данных в разы.
* 🎨 **Современный GUI-интерфейс**: Чистый графический интерфейс с использованием библиотеки `customtkinter` (светлая тема в стиле современных веб-сервисов).
* 📋 **Вставка в один клик**: Поддержка мгновенного импорта списка адресов из буфера обмена.
* 🧹 **Умная фильтрация контактов**:
  * Исключает ссылки на социальные сети (`t.me`, `instagram.com`, `facebook.com`, `linkedin.com` и др.) и помечает их для удобства.
  * Фильтрует ложные срабатывания (email-адреса, содержащие форматы картинок `.png`, `.jpg`, `.svg`, `.webp` и т.д.).
  * Исключает системные/мусорные домены.
* 💾 **Удобный экспорт**: Сохранение результатов в формате `.csv` с кодировкой `utf-8-sig` для беспроблемного открытия в Microsoft Excel без кракозябр.

---

## 🛠️ Стек технологий

* **Язык**: Python 3.10+
* **Интерфейс**: CustomTkinter
* **Скрейпинг / Браузер**: Playwright (асинхронный режим Chromium)
* **Асинхронность**: `asyncio` + `threading` (чтобы GUI не зависал во время сбора данных)
* **Сборка в EXE**: PyInstaller

## 🚀 Быстрый старт

### 1. Установка зависимостей
Сначала клонируйте репозиторий и установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

> **Важно**: После установки Playwright необходимо загрузить системные бинарные файлы браузера Chromium:
> ```bash
> playwright install chromium
> ```

### 2. Запуск приложения

Для запуска обычной (последовательной) версии:
```bash
python main.py
```

Для запуска ускоренной (асинхронной параллельной) версии:
```bash
python main2.py
```

### 3. Сборка в один клик (.exe)
Если вы хотите собрать автономный исполняемый файл для Windows:
```bash
pyinstaller main.spec
```
Исполняемый файл появится в папке `dist`.

## 📂 Структура проекта

* `main.py` — Базовая версия парсера (последовательный обход сайтов).
* `main2.py` — Рекомендуемая версия (многопоточный асинхронный парсинг).
* `main.spec` — Спецификация для сборки `.exe` файла через PyInstaller.
* `.gitignore` — Список исключений для Git (скрывает кэш, виртуальное окружение, папки сборки и файлы результатов).
